# Attach or compute scene geometry

Attach or compute scene geometry

## Usage

``` r
cl_geometry(x, lon = NULL, lat = NULL)
```

## Arguments

- x:

  A `cl_scene`.

- lon:

  Scene centre, used when metadata angles are absent.

- lat:

  Scene centre, used when metadata angles are absent.

## Value

The scene with `solar_geom` populated.
