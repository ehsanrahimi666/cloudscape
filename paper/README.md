# Manuscript materials

Everything here is regenerated by `Rscript paper/analysis.R` from the package
root. No result depends on a live satellite archive.

| File | Contents |
|---|---|
| `manuscript.md` | Full manuscript, title to references |

| `figures/` | Five PDF figures |

| `architecture-check.txt` | Layer contract and documentation checks |

## Before submission

1. Run `tools/integration-check.R` against live catalogues.
2. Complete the reference list — see the verification note at the end of
   `manuscript.md`. Fourteen works are cited in text but not yet in the list.
3. Insert the funding statement in the Acknowledgements.
4. Confirm the CRAN name with `available::available("cloudscape")`.
